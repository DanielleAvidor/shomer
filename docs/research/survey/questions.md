# Survey: exact questions (Google Form, Hebrew, anonymous)

Anonymous: no name, phone or email collected; all questions optional; sent by link to friends and acquaintances (not family). Question 3 allows several answers. On 2026-11-27 access was changed to anyone with the link, after friends who opened it asked for access.

1. How old are you? Under 30 / 30-40 / 40-75 / over 75
2. Which phone do you have? Android / iPhone / basic phone without internet / don't know
3. In the last six months, did you get a suspicious message (for example one that looks like Israel Post, your bank, a fine or a refund)? What did you do? (several allowed) Did not get one / ignored / asked family or a friend / checked myself on the official site or app / sent the message to an AI chat and asked if the link is valid / clicked the link / gave details or paid
4. If the phone warned you by itself, which warning would be clearest? "Do not tap the link. It does not lead to the Israel Post site." / "Dangerous message" / "This is a scam" / something else
5. If a message looks like a scam, would you want a family member to get an alert about it? Yes, every time / yes, but only when the danger is clear / no, I manage / don't know
